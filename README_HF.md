# 🎙️ VoxSense — High-Performance Speech Emotion Recognition Cloud Engine

VoxSense is a flagship, enterprise-grade Speech Emotion Recognition (SER) cloud service. By leveraging **ONNX Runtime** for lightweight neural network execution and **PyTorch CPU** for state-of-the-art transformer pipelines, VoxSense provides ultra-low latency audio classification.

- **Developer**: Raul909
- **Optimization**: CPU-only PyTorch and TensorFlow-CPU Docker builds (under 800MB!).
- **Engine**: ONNX Runtime (<150MB RAM runtime footprint).
